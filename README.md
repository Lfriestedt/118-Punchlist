# 118 Punch List

Live site: https://lfriestedt.github.io/118-Punchlist/

- `index.html` is the website.
- `data.json` holds every unit and punch item. The site updates it for you.
- `photos/` holds item photos.

Anyone with a link or QR code can view. Only someone signed in with an access token for this repository can add, edit, or delete.
